# Network Visualizer

A visual topology of Swarm networks and the containers attached to them.

![Screenshot of Network Visualizer page - Screenshot of the Network Visualizer showing columns for each network with attached containers listed inside.](/docs/wiki/screenshots/17.network-visualizer.png)

## Page Details
Renders a grid where each column represents a Network (e.g., overlay). Inside each network block, it lists the containers attached to it, showing their state and stack affiliation. Includes filters for scope (All/Swarm/Local).

## Dialogs
No dialogs.
