# Network Visualizer

A visual topology of Swarm networks and the containers attached to them.

![Screenshot of Network Visualizer page - Screenshot of the Network Visualizer showing columns for each network with attached containers listed inside.](/docs/wiki/screens/17-network-visualizer.png)

## Status Indicators
- **running** (Green): Indicates the item is running.
- **exited** (Red): Indicates the item is exited.
- **created** (Blue): Indicates the item is created.
- **restarting** (Orange): Indicates the item is restarting.

## Buttons
- **Search Input**: Filters the list of items based on the input query.
- **All Scopes**: Triggers the all scopes action.
- **Swarm (Overlay)**: Triggers the swarm (overlay) action.
- **Local**: Triggers the local action.
- **Refresh**: Reloads the current data from the manager.

## Dialogs
No dialogs are present on this view.
