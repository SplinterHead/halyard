# Settings: Events

A global audit log of deployment events and system actions.

![Screenshot of Settings: Events page - Screenshot of the Events view showing a data table of system events.](/docs/wiki/screenshots/24.settings-events.png)

## Page Details
Displays a searchable history of deployment events. Shows an empty state if no events have occurred. Lists stack names and associated event details when populated.

## Dialogs
No dialogs.
