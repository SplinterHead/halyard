# Settings: Events

A global audit log of deployment events and system actions.

![Screenshot of Settings: Events page - Screenshot of the Events view showing a data table of system events.](/docs/wiki/screens/24-settings-events.png)

## Status Indicators
- **Active** (Green): Indicates the item is active.
- **Inactive** (Grey): Indicates the item is inactive.

## Row Actions
- **Clicking a row**: No default action. Use the action buttons for interactions.

## Buttons
- **Search Input**: Filters the list of items based on the input query.
- **Refresh**: Reloads the current data from the manager.

## Dialogs
No dialogs are present on this view.
